# Version 8 Engineering Workbench

Version 8 adds integrated structural semantics, specialized behavior element definitions, requirements lifecycle and baselines, editable tables and relationship matrices, parametric constraint evaluation and Monte Carlo runs, instance/configuration modeling, profiles and mounted read-only libraries, ReqIF/XMI/CSV/SVG/PNG/archive interchange, and deeper validation.

The model remains a blank repository until the user creates or imports content. All workbench editors operate on the same semantic model used by diagrams and collaboration.

## Interchange qualification

ReqIF and XMI exports are open-format implementations. CATIA/Cameo proprietary compatibility must be regression-tested against the exact licensed releases and organization-specific workbook profiles before being used as an unattended production interchange pipeline.
