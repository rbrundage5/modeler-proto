# SysML v1 visual notation conformance matrix

Baseline: OMG SysML 1.7 and inherited OMG UML 2.5.1 notation. “Supported” means enabled by the current semantic profile; it does not by itself imply conformance. Statuses are conservative. The repository icons are tool chrome and are outside this matrix.
